# Changelog

Copyright (c) 2026 D Cube Consulting. All rights reserved.

All notable changes to this module are documented in this file.

## 1.0.5 (November 18, 2026)

- Enh: Administrators can upload a banner and choose whether it is shown across the top of the feed
- Fix: The banner preview stays inside the feed configuration panel

## 1.0.4 (November 18, 2026)

- Fix: Announcement previews stay inside the column when the theme uses large headings
- Enh: Administrators choose how many lines of each announcement to show before Read more
- Enh: The composer opens with the editor first and no posting destination selected
- Enh: Submit stays disabled until Everyone or at least one selected space is chosen
- Fix: Posting clears the selected audience so the composer is ready for the next post
- Fix: Everyone creates one profile post, the same as the dashboard, instead of a copy in every space

## 1.0.3 (November 17, 2026)

- Enh: An announcement links to its post through Read more, and the title and text are no longer a link
- Fix: Announcement links keep the colour and underline from the active theme
- Fix: The announcements widget lists only pinned posts, and keeps their original formatting
- Enh: Each announcement shows the first five lines, then Read more

## 1.0.2 (November 17, 2026)

- Enh: With Classified Spaces enabled, the space picker and shortcuts list spaces inside their categories, in the sort order set there
- Fix: A post with a file is saved in every selected space, not only the first
- Enh: Announcement headings and space names are larger, and each space name opens that space
- Enh: The feed uses HumHub's live poll and shows the same new-posts banner as a space or the Dashboard

## 1.0.1 (November 17, 2026)

- Enh: The space picker uses columns when a member can post in many spaces
- Fix: The composer opens with no space selected
- Enh: Administrators can leave Feed off the top bar

## 1.0.0 (November 17, 2026)

- Enh: Three-column feed of posts from spaces a member belongs to
- Enh: Composer posts to every space a member can use, or to the spaces they select
- Fix: A post to several spaces was saved only in the first space on the list
- Fix: A post sent to several spaces appears once in the feed, with each space named on it
- Fix: Space names on a shared post stay on one line
- Enh: Announcements rail for pinned posts, and a shortcuts rail for profile and spaces
- Enh: Administrators choose whether the feed sits beside the Dashboard or replaces it, and which widgets are on by default
- Enh: Members can show, hide, reorder, or reset those widgets
