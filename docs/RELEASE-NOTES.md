# Thiscovery Feed 1.0.4

**18 November 2026**

Copyright (c) 2026 D Cube Consulting. All rights reserved.

## Highlights

- Everyone creates one post on the member's profile, the same as the Dashboard. It no longer copies the post into every space.
- The composer opens with the editor first and no destination selected. The space list stays closed until Selected spaces is chosen.
- Submit stays disabled until Everyone is chosen, or Selected spaces has at least one space. The choice clears after the post is sent.
- Announcement previews stay inside the column when the theme uses large headings.
- Administrators set how many lines of each announcement to show before Read more. The default is five.

## Requirements

- HumHub 1.18 or later
- PHP 8.2 or later

## Upgrade

Replace the module with this release. Open **Administration → Thiscovery Feed** to set the announcement line count. Existing posts that were copied into every space are left as they are.
